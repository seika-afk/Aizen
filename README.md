# AIZEN : Rewrite your images
A web based AI Iage editor , That allows you to edit images using Natural language, with the help of my new friend open router and old friend ffmpeg .

### How to run 
1. Git clone the repo
2. Install the js libraries needed
```
cd aizen
npm install
```
3. Setup `.env` -> :`OPENROUTER_API_KEY`
(also install ffmpeg on your system , if its not present already)
5. Run The ui
```
npm run dev
```
5. Open `localhost:3000` on your browser
6. Enjoy
